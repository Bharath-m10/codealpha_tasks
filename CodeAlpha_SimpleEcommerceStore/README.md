# CodeAlpha_SimpleEcommerceStore
Task 1 for CodeAlpha Full Stack Development Internship.

## Features
- Product listing & detailed product modal
- Shopping cart calculation and dynamic quantity counter
- User authentication (Register & Login API)
- Order checkout and tracking endpoint

## How to Run
1. Open terminal inside this folder.
2. Run `npm install`
3. Run `npm start`
4. Open `http://localhost:3000` in your web browser.
