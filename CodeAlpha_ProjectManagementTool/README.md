# CodeAlpha_ProjectManagementTool
Task 3 for CodeAlpha Full Stack Development Internship.

## Features
- Kanban dashboard with To Do, In Progress, and Done lanes
- Create, reassign, update state, and delete tasks
- Responsive board layout
- Full Express REST API backend

## How to Run
1. Open terminal inside this folder.
2. Run `npm install`
3. Run `npm start`
4. Open `http://localhost:3002` in your web browser.
