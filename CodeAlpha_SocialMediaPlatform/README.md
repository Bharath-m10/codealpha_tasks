# CodeAlpha_SocialMediaPlatform
Task 2 for CodeAlpha Full Stack Development Internship.

## Features
- User profile card with live follow counter
- Post creation feed
- Like counter toggle
- Nested comment system for posts

## How to Run
1. Open terminal inside this folder.
2. Run `npm install`
3. Run `npm start`
4. Open `http://localhost:3001` in your web browser.
